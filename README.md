# MAPA-INTERACTIVO-POBLACION-HABITANTE-DE-CALLE-EN-C-CUTA
Aplicación web (HTML, CSS y JS) sobre el aumento de habitantes de calle en Cúcuta. En diez secciones integra mapas interactivos con Leaflet y Google My Maps, línea de tiempo histórica, caracterización de actores, mapas de afectaciones comunitarias y propuestas de resocialización y construcción de paz.
